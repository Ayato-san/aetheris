# Montserrat pour les composants Penpot

Les trois faces latines 400, 500 et 700 proviennent des fontes WOFF2 intégrées dans
`base-doc/design-system-penpot-export.html`, fourni comme référence visuelle.
Elles sont converties en TrueType pour le chargement natif par GPUI sous Linux
et Windows. Les contours, métriques, caractères et poids de l’export sont conservés.
Seuls les noms de famille et de faces sont harmonisés sous le nom privé
« Aetheris Montserrat », afin d’éviter les différences de regroupement des noms
internes de l’export et les collisions avec les polices du système.

Ces fontes couvrent le jeu latin de l’export, dont les caractères français.
GPUI peut utiliser ses fontes de repli pour les autres caractères.
